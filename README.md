# intermediate-machine-learning
**Semester 6 – Machine Learning (University Coursework)**  

## Overview  
This repository documents the successful completion of the **Intermediate Machine Learning** course offered by Kaggle as part of the 6th semester Machine Learning curriculum. The course builds upon foundational ML concepts and focuses on handling real-world datasets, improving model performance, and avoiding common modeling mistakes.

- **Platform:** Kaggle  
- **Instructor:** Alexis Cook  
- **Estimated Duration:** 4 Hours  
- **Cost:** Free  
- **Course Type:** Kaggle Learn (Certificate Earned)  

---

## Prerequisites  
This course builds on knowledge from:
- Intro to Machine Learning  
- Pandas (Python library for data manipulation)  

It also prepares students for:
- Feature Engineering  
- Time Series Analysis  

---

## Lessons Covered  

### 1. Introduction  
- Course overview and required background knowledge  
- Review of machine learning fundamentals  

### 2. Missing Values  
- Identifying missing data  
- Techniques for handling missing values  
  - Dropping columns  
  - Imputation strategies  

### 3. Categorical Variables  
- Handling non-numeric data  
- One-Hot Encoding  
- Ordinal Encoding  
- Selecting appropriate encoding techniques  

### 4. Pipelines  
- Creating structured ML workflows  
- Combining preprocessing and modeling steps  
- Writing clean and deployable ML code  

### 5. Cross-Validation  
- Understanding model validation techniques  
- Implementing K-Fold Cross-Validation  
- Improving model reliability and performance evaluation  

### 6. XGBoost  
- Introduction to gradient boosting  
- Training and tuning XGBoost models  
- Comparing performance with baseline models  

### 7. Data Leakage  
- Understanding data leakage  
- Identifying leakage in datasets  
- Preventing leakage to ensure realistic model performance

## Learning Outcomes  

After completing this course, I am able to:

- Handle missing and categorical data effectively  
- Build and implement machine learning pipelines  
- Apply cross-validation for reliable model evaluation  
- Use XGBoost for structured datasets  
- Detect and prevent data leakage  
- Improve model accuracy using advanced techniques
